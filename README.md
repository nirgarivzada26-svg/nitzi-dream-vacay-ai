# NITZI: Your Personalized Vacation AI

אני רוצה לבנות אפליקציה חדשה בשם NITZI.

NITZI היא פלטפורמת AI לתכנון חופשות וחוויות.
המטרה היא ליצור עוזר אישי חכם שמבין את המשתמש ובונה לו חופשה מותאמת אישית.

בשלב הזה אני רוצה לבנות MVP בלבד — בלי הזמנות אמיתיות ובלי חיבור לטיסות או מלונות.

תתחיל בבניית חוויית המשתמש והעיצוב.

דרישות:

דף בית ראשי:

לוגו NITZI

עיצוב יוקרתי, צעיר ומודרני
